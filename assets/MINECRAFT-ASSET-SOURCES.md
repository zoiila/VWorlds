# Minecraft artwork attribution — VWorld diagrams

The Grass Block artwork in VWorld's **public README diagrams** was created from the original **Minecraft: Java Edition 26.2** texture files. It is an illustrative example of an Overworld block, **not a screenshot**, and does not suggest that every schematic contains a Grass Block.

## Original game sources

**Minecraft** and the Grass Block textures belong to **Mojang Studios / Microsoft**. These materials are not original VACK STUDIO artwork, and this project is not endorsed by or affiliated with Mojang or Microsoft.

The exact source branch is [InventivetalentDev/minecraft-assets, version `26.2`](https://github.com/InventivetalentDev/minecraft-assets/tree/26.2/assets/minecraft/textures/block), an extracted mirror of Minecraft's Java game assets:

- `assets/minecraft/textures/block/grass_block_top.png`
- `assets/minecraft/textures/block/grass_block_side.png`
- `assets/minecraft/textures/block/grass_block_side_overlay.png`
- `assets/minecraft/models/block/grass_block.json`

The small `grass-block-vanilla-26.2.png` icon composites those actual 16×16 textures over orthographic faces, applies an illustrative Plains-like grass tint and face shading, and keeps the original pixel artwork. It does **not** use AI-generated block textures or generic hand-drawn cube faces.

The `SOURCE TEMPLATE` illustration represents an **example Overworld schematic**; the ownership graphic depicts the registered `.schem` using a generic **document icon**, while only the resulting Minecraft world uses the textured Grass Block.

For additional information about permitted use of Minecraft branding and game assets, consult [Minecraft Usage Guidelines](https://www.minecraft.net/usage-guidelines).
